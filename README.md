# FSG Datenblatt Control Center

Version 2 der FSG-Datenblattplattform. Dieses Repository entwickelt die transparente Produkt- und Prozesssteuerung weiter, während das Produktionssystem `dahahn1980/fsg-datenblatt-system` als stabile V1-Referenz erhalten bleibt.

Der Aufbau erfolgt in einem Pull Request. Die PDF-Engine wird zunächst unverändert und auf einen freigegebenen V1-Commit fixiert übernommen.
